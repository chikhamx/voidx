## 模型与 Provider

支持多 provider 配置，随时切换。

| 命令 | 作用 |
|------|------|
| `/model` | 切换模型 |
| `/model new` | 创建或更新模型 profile |
| `/model list` | 查看已配置模型详情 |
| `/model switch` | 切换 provider |
| `/model test` | 测试 provider 连通性 |
| `/model del` | 删除 profile |
| `/model reasoning` | 设置推理强度 |
| `/model ctx` | 设置上下文窗口大小 |
