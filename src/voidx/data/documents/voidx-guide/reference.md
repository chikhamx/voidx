## 命令速查

| 命令 | 一句话 |
|------|--------|
| `/help` | 显示所有命令 |
| `/exit` `/quit` | 退出 |
| `/paste` | 从剪贴板粘贴图片 |
| `/clear` | 开新会话 |
| `/list` | 列出会话 |
| `/resume` | 恢复会话 |
| `/rollback` | 回滚当前轮次 |
| `/model` | 切换模型 |
| `/mode` | 切换交互模式 |
| `/plan` `/unplan` | 进入/退出 plan 模式 |
| `/goal` | 设置目标 |
| `/permissions` | 查看权限规则 |
| `/sandbox` | 设置沙箱 |
| `/approval` | 设置审批策略 |
| `/compact` | 压缩上下文 |
| `/usage` | 查看 token 用量 |
| `/diff` | 查看 git diff |
| `/mcp` | 管理 MCP 服务器 |
| `/lsp` | 管理语言服务器 |
| `/skills` | 管理技能 |
| `/init` | 生成 AGENTS.md |
| `/lang` `/tone` | 语言/语气偏好 |
| `/upgrade` | 检查/执行升级 |
| `/debug` | 调试输出开关 |
| `/log` | 日志开关 |
